# Synora AI

AI-powered workflows for modern teams and creators.

🔗 **Live site:** [synorae-ai.netlify.app](https://synorae-ai.netlify.app/)

Synora AI is a SaaS landing page for an AI-powered productivity platform. It showcases intelligent workflow automation, analytics, and collaboration features through pricing plans, testimonials, and FAQs, with a clean, conversion-focused design.


## ✨ Features

- Animated hero section and scroll-based reveals powered by GSAP
- Smooth scrolling experience across the page
- Sections for Features, Stats, Testimonials, Pricing, and FAQ
- Newsletter signup and Contact page
- Privacy Policy page and placeholder "Coming Soon" pages for future routes (Integrations, Docs, Blog, About, Careers, Legal)
- Fully responsive layout
- Deployed on Netlify with SPA redirect handling

## 🛠️ Tech Stack

| Category    | Tools |

## 🚀 Getting Started

Clone the repo and install dependencies:

```bash
git clone https://github.com/chaimabidqui/Synora-AI.git
cd Synora-AI/my-app
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Lint the project:

```bash
npm run lint
```
